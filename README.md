# Portafolio profesional de Miguel Olivares

Sitio web bilingüe (español / inglés) construido a partir de una base generada con Mobirise y adaptado como hoja de vida web y portafolio profesional.

## Estado actual

- Versión en español en `index.html`
- Versión en inglés en `en.html`
- Selector de idioma al abrir el sitio y cambio manual desde el menú
- Diseño ajustado para mejor visualización en escritorio y móvil
- Navegación superior personalizada con foto de perfil
- Secciones de experiencia, investigación y formación con detalle visual
- Especialidades ilustradas con imágenes personalizadas
- Perfil de audio con reproductores embebidos de SoundCloud

## Estructura del proyecto

- `index.html`: versión principal en español
- `en.html`: versión principal en inglés
- `assets/`: imágenes, hojas de estilo, librerías y recursos del sitio
- `project.mobirise`: archivo fuente para edición desde Mobirise
- `CONTENT_GUIDE.md`: guía de referencia para futuras actualizaciones de contenido

## Contenido actual del sitio

- Perfil profesional
- Especialidades
- Experiencia profesional
- Experiencia docente
- Experiencia en investigación
- Educación y formación
- Proyectos destacados
- Contacto y redes

## Edición de contenido

Para actualizar el sitio:

1. Editar `index.html` para la versión en español
2. Editar `en.html` para la versión en inglés
3. Agregar imágenes nuevas en `assets/images/`
4. Verificar que los enlaces, textos y recursos se mantengan sincronizados en ambos idiomas

## Publicación en GitHub Pages

Este proyecto ya está preparado para subirse a GitHub y publicarse con GitHub Pages.

Pasos sugeridos:

```bash
git add .
git commit -m "Initial portfolio site"
git push -u origin main
```

Luego en GitHub:

1. Ir a `Settings`
2. Abrir `Pages`
3. En `Build and deployment`, elegir `Deploy from a branch`
4. Seleccionar `main` y la carpeta `/ (root)`

## Recomendaciones

- Mantener `index.html` y `en.html` alineados en estructura
- Guardar nuevas imágenes optimizadas antes de subirlas
- Usar `assets/images/` para todos los recursos visuales personalizados
- Evitar versionar archivos temporales o exportaciones intermedias
