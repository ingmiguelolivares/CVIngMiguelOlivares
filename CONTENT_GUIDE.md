# Guía de contenido del portafolio

Este documento sirve como referencia para mantener actualizado el sitio web profesional de Miguel Olivares en español e inglés.

## 1. Perfil profesional

Actualizar cuando cambie alguno de estos elementos:

- nombre profesional
- resumen corto
- enfoque principal
- años de experiencia
- áreas de trabajo prioritarias

## 2. Especialidades

El sitio actualmente organiza esta sección en tres bloques:

- audio, sonido y producción musical
- desarrollo interactivo y programación
- docencia y liderazgo académico

Para cada bloque conviene mantener:

- imagen representativa
- texto corto descriptivo
- herramientas, tecnologías o enfoques principales

## 3. Audio y producción musical

Esta especialidad ya incluye recursos embebidos de SoundCloud.

Cuando se actualice, revisar:

- nuevos temas o jingles publicados
- enlaces activos de SoundCloud
- orden de prioridad de los audios destacados
- descripción del perfil de audio

## 4. Experiencia profesional

Cada entrada debería conservar:

- institución o empresa
- rol
- rango de años
- funciones principales
- logros relevantes

Actualmente el sitio separa visualmente:

- experiencia laboral
- experiencia docente
- experiencia en investigación

## 5. Investigación

Para mantener esta sección al día, registrar:

- nombre del proyecto
- institución
- rol desempeñado
- periodo
- objetivo o alcance
- aportes o resultados destacados

También conviene diferenciar entre:

- proyectos certificados
- proyectos PIC
- participación como coinvestigador

## 6. Educación y formación

La línea de tiempo de formación debe incluir:

- título o programa
- institución
- año o periodo
- énfasis o contexto si aporta valor

## 7. Proyectos destacados

Para cada proyecto destacado conviene tener:

- nombre
- descripción breve
- imagen representativa
- tecnologías involucradas
- enlace externo, demo o referencia si existe

## 8. Contacto y presencia digital

Revisar periódicamente:

- correo principal
- teléfono
- ciudad / país
- LinkedIn
- GitHub
- SoundCloud
- otros enlaces públicos relevantes

## 9. Imágenes y recursos visuales

Toda imagen nueva debe:

- guardarse en `assets/images/`
- tener nombre claro y estable
- estar optimizada para web
- usarse en ambas versiones del sitio si aplica

## 10. Trabajo bilingüe

Cada cambio importante debe replicarse en:

- `index.html` para español
- `en.html` para inglés

Verificar siempre:

- consistencia entre contenidos
- traducción natural
- enlaces correctos en ambas páginas
- títulos y botones sincronizados

## 11. Antes de publicar cambios

Checklist recomendado:

- revisar visualmente escritorio y móvil
- probar enlaces y reproductores embebidos
- confirmar imágenes correctas
- validar que español e inglés estén alineados
- revisar `README.md` si cambia la estructura del proyecto
